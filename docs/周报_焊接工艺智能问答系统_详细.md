# 周报：焊接工艺智能问答系统（详细版·两周）

**周期**：2026.08.11 - 08.22（8 个工作日）

**项目定位**：面向机器人焊接的工艺知识引擎 —— 查参数 → 出机器可读工艺卡片 → 指导机器人仿真/路径规划/操控

## 一、8 天工作明细（每天）

### Day 1（8.11）：项目基线 + 卡诺普数据初探
- **梳理系统现状**：确认默认工艺为焊条电弧焊（SMAW）、偏人工焊，与机器人焊接需求不符
- **定位核心问题**：手册偏人工焊、参数是范围值、无机器人姿态/层道数据
- **团队分工**：确立 4 人分工（检索/性能/数据/测试）
- **产出**：问题清单 + 技术路线（查参数→卡片→机器人）

### Day 2（8.12）：卡诺普真值库导入（第一批）
- **解析卡诺普 Excel**：发现 4 个主参数 sheet（碳钢中厚板/薄板/镀锌板/不锈钢）
- **导入 206 条真值**（基准参数：材料/板厚/焊缝形式→电流/电压/速度/角度）
- **工艺卡片接入真值**：卡片优先输出真值，标注"卡诺普实测"
- **产出**：`data/weld_cases.json`（206条）+ 工艺卡片真值输出
- **验证**：碳钢5mm船型→250A/23.5V/角度(80,90)/摆幅3

### Day 3（8.13）：机器人焊接能力
- **默认工艺切换**：SMAW→GMAW/MIG（机器人焊丝工艺）
- **新增机器人规则库** `robot_welding.py`：焊丝选型/保护气/TCP/枪姿态/船型焊
- **层道序列**：打底/填充/盖面具体电流电压（12mm板：120-140A→160-190A→180-210A）
- **管道场景**：固定管 6G 半圈分段策略
- **产出**：机器人工艺卡片（含船型焊/管道6G/层道序列）

### Day 4（8.14）：专家库概念构建
- **专家库概念 123→152**（+29：CE/Pcm/UT/RT 缩写、手把焊/船型焊同义）
- **概念触达率 100%**（152/152 规范词可触达）
- **概念定义质量**：手工定义表 + 干净文字（不抓 OCR 原文）
- **修复**：氩弧焊被埋弧焊抢答、乱码过滤、来源排序
- **产出**：专家知识库 152 概念全达标

### Day 5（8.15）：测试体系 + 归一化
- **繁简归一化表 82→235 字**（氬→氩、鏽→锈等）
- **专项测试集 53 条**（繁体23/缩写16/同义14），命中率 30%→100%
- **归一化接入全链路**：缓存键/向量/RAG 三层统一
- **跨书融合检索**：本地提取词兜底 + 英文缩写大小写兼容
- **产出**：测试套件 normalization + chain 全过

### Day 6（8.18）：卡诺普全量 + 语义向量
- **发现 25 个 sheet**（不止 4 个主表），重新全量导入
- **1340 条真值**（基准206 + 电流/电压/速度变化1134）
- **变体支持**：问"电流大/速度快"取对应范围（170A vs 150A）
- **bge 语义向量**接入（modelscope，512维），检索精度提升
- **产出**：真值库 1340 条 + 语义向量检索

### Day 7（8.19）：焊接结构原理 GPU OCR 重跑
- **303 页扫描版 PaddleOCR 重跑**（2.2s/页）
- **质量提升**：关键词 123→562、表格 1→9、字数 80K→209K
- **表格重建**：232 候选页定向 OCR → 9 个结构化表格
- **产出**：焊接结构原理数据质量大幅提升

### Day 8（8.20-8.22）：技术债 + 收尾
- **git 历史清理**：.git 1.1GB→94MB（-91%），API key 历史抹除
- **P0/P1 问题修复**：三层匹配融合、OCR 乱码过滤、归一化对齐
- **测试扩充**：工艺卡片真值 7 条 + 真实场景 E2E 7 条
- **性能基线**：首次 34-49ms、缓存命中 100% 62ms
- **初级风险**：模型下载脚本 + 性能基线脚本
- **产出**：全量测试 9 组 PASS + 远程仓库清理
