## 二、数据缺口 + 公开资源（徐采妮重点）

### 1. 铝合金真值
**可参考资源**：
- 铝合金焊接共享数据库系统的期刊论文（工艺参数+材料匹配）
- AWS（美国焊接学会）铝合金标准焊接工艺规程（SWPS）草案
- 铝合金焊丝标准（GB/T 10858 铝及铝合金焊丝）
- 期刊：《焊接学报》《中国有色金属学报》铝合金焊接工艺参数

**可提取**：电流/电压/焊速/焊丝牌号/保护气 → 填入真值库

### 2. 铸铁真值（最权威，优先）
**可参考资源**：
- **GB/T 44841-2024《非合金及低合金铸铁焊接工艺评定试验》**（2025年5月实施）★最权威
- 铸铁焊条标准（GB/T 10044）
- Z308/Z408 焊条厂家工艺参数

**可提取**：预热温度/电流/焊条牌号/焊接工艺 → 填入真值库

### 3. 管道 6G 焊接参数
**可参考资源**：
- 海底管线 6G 位置焊接参数专利
- 6G 位置不锈钢管 GTAW 焊接工艺论文
- 6G 位置 GTAW 操作方法/参数综述文章
- ISO 9606-1（焊工考核）/ API 1104（管道焊接）

**可提取**：分段角度/电流电压/焊层安排 → 管道卡片真值

### 4. 真实用户问答对
**可参考资源**：
- 论文/专利的"背景技术"和"具体实施方式"（隐含工程问题+解决方案）
- 焊接论坛/社区高频问题（焊缝缺陷/参数选择）
- 标准条文的"为什么"（如预热为什么、探伤为什么）

**可转化**：→ 问答对（Q: 现象/问题，A: 原因/方案）

## 三、数据模板设计（喂数据标准格式）

### 1. 工艺参数真值模板（Excel/CSV）
每行一条真值，列与卡诺普一致：
```
材料 | 气体 | 焊丝直径 | 板厚/焊脚 | 焊缝形式 | 电流 | 电压 | 焊接速度 | 干伸长 | 焊枪角度(前后) | 焊枪角度(左右) | variant | 来源
铝合金 | 纯Ar | 1.2mm | 3mm | 平拼接 | 110 | 19.5 | 35 | 15 | 80 | 90 | 基准 | GB/T+论文
```
- **variant**：基准/电流小/电流大/电压小/电压大/速度快/速度慢/角度范围
- **来源**：标准号/论文名（可追溯）

### 2. 问答对模板（JSON）
```json
{
  "q": "铝合金焊接为什么容易产生气孔？",
  "a": "氢在液态铝中溶解度远高于固态，凝固时析出形成气孔；需清理氧化膜、控制保护气",
  "topic": "铝合金缺陷",
  "source": "GB/T 44841/论文",
  "level": "概念"        // 概念/参数/缺陷/工艺
}
```

### 3. 管道 6G 模板

## 四、数据怎么喂进系统（流程）

### 工艺参数真值 → 真值库
```
1. 按模板整理 Excel/CSV（徐采妮）
2. 追加到 tools/import_kanopu.py 的 SHEET_MAP 或直接补 weld_cases.json
3. 运行: python tools/import_kanopu.py <新数据.xlsx>
4. 工艺卡片自动优先取新真值
```

### 问答对 → 测试集 / 专家库
```
1. 按 JSON 模板收集（曾立夫）
2. 概念类 → 补 expert_knowledge_base 手工定义
3. 检索类 → 补 tools/tests.py 测试集
4. 运行: python tools/tests.py
```

### 管道 6G → 工艺卡片
```
1. 按模板整理（徐采妮）
2. 补 app/robot_welding.py 管道策略真值
3. 问"管道 6G 焊" → 卡片输出分段参数
```
