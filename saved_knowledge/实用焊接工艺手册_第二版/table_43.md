| 5.焊接工艺参数的选择 |  |  |
|  | 前面虽然已经讲到焊接工艺，即焊接时的电流和焊接速度，但 |  |
|  | 是只是典型情况下的一些基本焊接参数，不能代表所有条件下的焊 |  |
|  | 接，因此读者也不能机械地搬用这些数据。下面要讲的是各种工艺 |  |
| 参数的控制。 |  |  |
| （1）焊接热输人 | 热轧及正火钢焊接热输人的确定主要依据是 |  |
|  | 防止过热区脆化和焊接裂纹两个方面。由于各种热轧及正火钢的脆 |  |
| 化倾向和冷裂倾向不相同，因此对热输人的要求也不同。 |  |  |
